# Школьный рейтинг (React + Vite)

Фронтенд для рейтинга учеников с Excel-подобной таблицей на Handsontable, формулами на русском, авторизацией администраторов и онлайн-присутствием. Всё работает через Firebase (Auth, Firestore, Realtime Database) без собственного сервера.

## Возможности
- Три страницы через React Router: главная «Победители», «Полная таблица рейтинга» (Excel UX), «Импорт / Админ».
- Handsontable + HyperFormula с копированием, undo/redo, drag fill, фиксированной шапкой и первым столбцом, виртуализацией.
- Формулы вводятся на русском (=СУММ, =СРЗНАЧ, =МИН, =МАКС, =СЧЁТ); в Firestore хранится русская версия и нормализованная английская.
- Ролевой доступ: редактирование и импорт доступны только при наличии документа `admins/{uid}`.
- Реальное время: onSnapshot для `meta/workbook` и `cells`, Realtime Database для presence с подсветкой редактируемых ячеек.
- Импорт Excel с выбором листа, строки заголовков, предпросмотром и попыткой сохранения формул.

## Настройка Firebase
1. Создайте проект Firebase и включите Authentication (Email/Password), Firestore и Realtime Database.
2. Заполните `src/firebase.js` значениями вашего проекта.
3. Создайте пользователей `admin1@school.local`, `admin2@school.local` (пароли на ваше усмотрение) и отметьте их в коллекции `admins/{uid}` документом `{ role: "admin" }`.

### Структура данных Firestore
- `meta/workbook`: `{ rows, cols, colHeaders, rowHeaders }`.
- `cells/{row_col}`: `{ r, c, v, fRu, f, updatedAt, updatedBy }`.
- (опционально) `admins/{uid}` для прав.

### Presence (Realtime Database)
`presence/{uid} = { name, online, editing: { r, c } }`

## Запуск локально
```bash
npm install
npm run dev
```

Если установка пакетов блокируется прокси, попробуйте выполнить команды на среде с прямым доступом в интернет — Vercel использует публичный npm.

## Сборка
```bash
npm run build
```

## Деплой на Vercel
1. Создайте проект на Vercel и подключите репозиторий.
2. Добавьте переменные окружения Firebase в настройках проекта.
3. Команда сборки: `npm run build`, папка для выдачи: `dist`.

## Полезное
- Формулы отображаются на русском в формульной строке, в вычислитель уходит нормализованная версия.
- Импорт Excel принимает любой лист: выберите лист, строку заголовков и загрузите. Пустые строки и колонки фильтруются.
- Все обновления пишутся батчем, чтобы ускорить синхронизацию.
