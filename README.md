# Школьный рейтинг (React + Vite)

Новый интерфейс с отдельными страницами, таблицей «как в Excel», формулами на русском языке и синхронизацией через Firebase (Auth, Firestore, Realtime Database).

## Возможности
- **Маршрутизация**: `/` — Победители, `/table` — полная таблица, `/admin` — импорт и настройки.
- **Главная страница**: топ-3 и топ-10 участников по столбцу «Итого/Баллы» с фильтром по классу.
- **Таблица как Google Sheets**: Handsontable + HyperFormula, редактирование, выделение диапазонов, копирование/вставка, undo/redo, автозаполнение, фиксированные шапка и первый столбец, виртуализация.
- **Формулы на русском**: `=СУММ`, `=СРЗНАЧ`, `=МИН`, `=МАКС`, `=СЧЁТ`; в Firestore сохраняется русская формула, движок переводит в английский для расчёта.
- **Реальное время**: onSnapshot для меты и ячеек, batch-сохранение правок, отображение кто и что редактирует через Realtime Database.
- **Импорт Excel**: выбор листа, строка заголовков, предпросмотр первых 10 строк, попытка переноса формул, загрузка в Firestore (`meta/workbook` + коллекция `cells`).
- **Права доступа**: чтение для всех, редактирование только при наличии `admins/{uid}` в Firestore.

## Firebase структура
- `meta/workbook` — `{ rows, cols, colHeaders: string[], rowHeaders: boolean }`
- `cells/{row_col}` — `{ r, c, v, f (русская формула или null), updatedAt, updatedBy }`
- `presence/{uid}` (Realtime Database) — `{ name, online, editing: { r, c } }`
- `admins/{uid}` — `{ role: "admin" }`

## Запуск локально
1. Установите зависимости (потребуется доступ к npm):
   ```bash
   npm install
   ```
2. Заполните `src/firebase.js` данными вашего проекта Firebase.
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
4. Откройте `http://localhost:5173`.

## Деплой на Vercel
1. Создайте новый проект Vercel и подключите репозиторий.
2. Укажите переменные окружения для Firebase (если не храните конфиг в репо).
3. Команда билда по умолчанию: `npm run build`. Output directory: `dist`.
4. После деплоя убедитесь, что домен добавлен в `authDomain` Firebase.

## Импорт Excel
1. Откройте `/admin` под администратором.
2. Выберите файл `.xlsx`, затем лист и номер строки заголовков (0 — первая строка).
3. Проверьте предпросмотр, нажмите «Загрузить в Firestore» — мета и ячейки будут заменены.

## Формулы на русском
- Поддерживаются: `СУММ`, `СРЗНАЧ`, `МИН`, `МАКС`, `СЧЁТ`.
- В интерфейсе вводите русские формулы. Приложение сохраняет их в Firestore и переводит в английский для HyperFormula.

## Скрипты
- `npm run dev` — запуск dev-сервера Vite.
- `npm run build` — продакшен-сборка.
- `npm run preview` — предпросмотр собранного проекта.
